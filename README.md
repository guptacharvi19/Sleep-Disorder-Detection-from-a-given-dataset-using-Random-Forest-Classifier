# Sleep-Disorder-Detection-from-a-given-dataset-using-Random-Forest-Classifier

This project presents a comprehensive data-driven approach to identifying and classifying sleep disorders
using machine learning techniques. The objective is to accurately categorize individuals into three diagnostic
groups: No Disorder, Insomnia, and Sleep Apnea. By leveraging advanced statistical methods and predictive
modeling, the study aims to uncover the underlying lifestyle and physiological patterns associated with poor
sleep health, enabling early intervention and improved clinical awareness.
The dataset contains 374 initial observations with 13 core features encompassing demographic details,
lifestyle habits, and physiological measurements including blood pressure, heart rate, stress level, and daily
physical activity. After data cleaning and preprocessing, the final dataset comprised 359 observations with 15
features, providing a holistic view of individual sleep behaviors and physiological conditions that contribute
to sleep disturbances.
The dataset presented several analytical challenges including 219 missing entries in the sleep disorder
label, inconsistent categorical formatting, and compound blood pressure readings requiring parsing. Through
systematic preprocessing, these issues were addressed to ensure analytical readiness. The Exploratory Data
Analysis (EDA) established the foundation for all subsequent phases, involving pattern evaluation, outlier
detection and treatment, creation of engineered metrics such as Sleep Efficiency, and analysis of relationships
between lifestyle factors and physiological measurements.
The project adopts a comprehensive methodological framework combining descriptive, inferential, and
predictive analytics. Descriptive EDA summarized dataset characteristics, inferential statistical tests identified
significant relationships among variables, and predictive modeling enabled classification performance
evaluation with cross-validation and hyperparameter optimization.
